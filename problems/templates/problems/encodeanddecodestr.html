Encode and Decode Strings

Given a list of strings, encode the list into a single string and then decode that string back into the original list of strings.

The important requirement is that the original strings must be recovered exactly, even if they contain spaces, numbers, or special characters.

Solution

class Solution:

    def encode(self, strs: list[str]) -> str:

        encoded = ""

        for s in strs:
            encoded += str(len(s)) + "#" + s

        return encoded


    def decode(self, s: str) -> list[str]:

        result = []

        i = 0

        while i < len(s):

            j = i

            while s[j] != "#":
                j += 1

            length = int(s[i:j])

            start = j + 1

            end = start + length

            result.append(s[start:end])

            i = end

        return result

class Solution {
public:

    string encode(vector<string>& strs) {

        string encoded = "";

        for (string s : strs) {

            encoded += to_string(s.length());
            encoded += "#";
            encoded += s;
        }

        return encoded;
    }


    vector<string> decode(string s) {

        vector<string> result;

        int i = 0;

        while (i < s.length()) {

            int j = i;

            while (s[j] != '#') {
                j++;
            }

            int length =
                stoi(s.substr(i, j - i));

            int start = j + 1;

            int end = start + length;

            result.push_back(
                s.substr(start, length)
            );

            i = end;
        }

        return result;
    }
};

class Solution {

    public String encode(List<String> strs) {

        StringBuilder encoded =
            new StringBuilder();

        for (String s : strs) {

            encoded
                .append(s.length())
                .append("#")
                .append(s);
        }

        return encoded.toString();
    }


    public List<String> decode(String s) {

        List<String> result =
            new ArrayList<>();

        int i = 0;

        while (i < s.length()) {

            int j = i;

            while (s.charAt(j) != '#') {
                j++;
            }

            int length = Integer.parseInt(
                s.substring(i, j)
            );

            int start = j + 1;

            int end = start + length;

            result.add(
                s.substring(start, end)
            );

            i = end;
        }

        return result;
    }
}

How It Works

Encoding

For every string, store:

length + "#" + string

For example:

["hello", "world"]

becomes:

5#hello5#world

Decoding

During decoding, first find #. Everything before # represents the length of the string.

5#hello

Here:

  • 5 → length
  • # → separator
  • hello → actual string

Therefore we know exactly how many characters to read after #.

Why Store the Length?

We cannot simply join strings using a normal separator because the separator might already appear inside a string.

For example:

["hello#world", "abc"]

If we simply use # as a separator, decoding becomes ambiguous.

With length encoding:

11#hello#world3#abc

The decoder knows that the first string has exactly 11 characters, so the # inside hello#world causes no problem.

Complexity

Encoding

Time Complexity: O(n)

Every character from the input strings is processed once.

Space Complexity: O(n)

The encoded string requires space proportional to the total number of characters.

Decoding

Time Complexity: O(n)

Every character of the encoded string is processed once.

Space Complexity: O(n)

The decoded strings require space proportional to the input size.
